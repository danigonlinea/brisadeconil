## Development

When starting the dev server, use background mode:

```
astro dev --background
```

Manage the background server with `astro dev stop`, `astro dev status`, and `astro dev logs`.

## Gallery image optimization

Gallery source photos live in `public/gallery/*.jpg` (full-resolution originals).
Optimized variants (AVIF/WebP/JPEG at 640/1600/2000px + an LQIP data URI) are
generated by a sharp script into `public/gallery/optimized/`, and a typed
manifest is emitted to `src/data/gallery-manifest.ts` (consumed by
`GalleryIsland.tsx`).

```bash
# (Re)generate all optimized variants + manifest. Idempotent — skips files
# newer than their source. Run this whenever you add or replace gallery photos.
npm run optimize:gallery
```

To force a full re-generation (e.g. after changing encode quality settings),
delete `public/gallery/optimized/` first. The script also runs automatically in
CI before `astro build` (see `.github/workflows/deploy.yml`).
